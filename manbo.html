使用指南

角色与限制

  • 先选角色（默认「曼波」），台词最多 10 段；「曼波」单段限 300 字，其他角色限 1024 字。
  • 「曼波」每天免费 50 次，超出会报错（源 API 站限制，前端无法解除）；其他角色暂无次数限制。
  • 若 API 报错为源站问题，一般等周末会恢复，可稍后再试。

批量导入

  • 支持 txt / json / csv / srt / vtt / ass / ssa / lrc，按 UTF-8 读取，自动分段。
  • 超过 10 段时会打开选择面板，可勾选要导入的段落，也支持按住鼠标拖动连续多选。
  • 导入会整体替换现有台词；导入过的文件可在「重新选取」里恢复上一次勾选。

试听与记录

  • 试听使用站点内置的本地音频，不占用生成次数；播放过的音频会缓存到本机浏览器，之后不再请求服务器。
  • 生成记录最多保留 100 条，存在本机浏览器，清除数据会丢失，请及时下载保存。

网络与付费

  • 如果音频无法播放 / 下载 / 加载慢，为源站问题，可稍后再试。
  • 所有生成音频统一经由 VKit 服务器代理分发；如需使用付费版：前往 VKit。
  • 语音生成由 Milora 提供 API 支持。
